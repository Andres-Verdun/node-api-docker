1.  ¿Qué hace git clone y dónde sitúa el control de versiones?
Lo que hace es clonar el repositorio de un usuario, descargarlo y poder subirlo despues a un repositorio propio.
En la carpeta local,donde tenes guardado los archivos, te crea una carpeta oculta .git, allí te aloja el contro de versiones.

es un archivo que contiene las instrucciones, las características de cómo construir una imagen, qué version de node usar, el packege json con las dependencias, en qué directorio hacerlo.
